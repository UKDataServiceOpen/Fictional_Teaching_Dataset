# Fictional Teaching Dataset: Household and Individual Survey Files

**About this repo**

This repository contains the dataset and supporting documentation, including the user guide, codebook and syntax files of the activity for the [Handling hierarchical files in survey data] (https://ukdataservice.ac.uk/learning-hub/) module, a data skills module published by the [UK Data Service] (https://ukdataservice.ac.uk/).


**About the dataset**

This dataset is entirely fictional and was created for teaching and practice.

It consists of two files:

  •	An individual-level file.
  
  •	A household-level file.

They contain artificially generated socioeconomic data that resemble the structure and coding of real survey data.


**Important information**

The data contain no information about real individuals or households. They are intended for teaching and training use only and should not be used for research or interpreted as findings from a real survey.


**About the Handling hierarchical files in survey data module**

The the [Handling hierarchical files in survey data] (https://ukdataservice.ac.uk/learning-hub/) module introduces hierarchical data and explains how to work with data organised at different levels, such as individuals within families, pupils within schools or employees within businesses.

The module is designed for learners with a basic understanding of survey data.

By the end of the module, users should be able to:

  •	Understand hierarchical data structures.
  
  •	Manage data at different levels.
  
  •	Merge datasets across hierarchical levels.
  
  •	Identify potential sources of error when merging data.
